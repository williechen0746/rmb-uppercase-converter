关于本工具

输入小写金额，即时转换成财务规范的人民币大写，可直接用于报销单、支票、合同及各类票据的填写。 全部计算在浏览器本地完成，输入的金额不会上传到任何服务器，无需注册、无需联网，打开即用、完全免费。

转换规则依据中国人民银行《支付结算办法》附一《正确填写票据和结算凭证的基本规定》。

支持范围：整数最多 20 位（到「亿亿」级），小数最多 2 位（角、分）。输入容错涵盖千分位 1,234.56、全角数字 １２３、¥ 符号与首尾空格；负数会在大写前加「负」。 格式与数值不合规时会给出提示，不做静默截断。

本工具为纯前端开源项目，源码托管于GitHub。

常见问题
大写金额一定要写「人民币」字样吗？
要写。依据《正确填写票据和结算凭证的基本规定》第三条，中文大写金额数字前应标明「人民币」字样， 并紧接填写、不得留有空白；未印「人民币」字样的，应加填「人民币」三字。本页的「加“人民币”前缀」 开关默认不勾选，便于只取纯大写数字；用于票据等正式凭证时应勾选。
金额到「角」为止时，后面要不要写「整」？
可写可不写。规定第二条：金额到「元」为止的，应在「元」后写「整」（或「正」）；到「角」为止的， 「角」之后可以不写。本工具默认写出「整」，可用「元」后写「整」开关关闭。
数字中间有 0 怎么写？
中间有 0 时写「零」，连续多个 0 只写一个「零」，例如 1001 写成壹仟零壹。 按第四条（三），万位或元位是 0 而千位、角位不是 0 时，中文大写可以只写一个「零」，也可以不写「零」； 本工具统一采用写一个「零」的写法。
输入的金额会被上传或保存吗？
不会上传。全部计算在本地浏览器完成，不联网、不写入服务器。「最近记录」仅保存在你自己浏览器的本地存储中， 随时可点该栏的「清除」删除。
可以填多大的金额？
整数最多 20 位，即到「亿亿」级；小数最多 2 位。超出范围或格式不合法时会给出提示，不做静默截断。
