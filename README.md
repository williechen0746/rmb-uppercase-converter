# 人民币大写转换工具

输入小写金额，实时转换成财务规范的人民币大写。纯前端单页，**无需安装、无需联网**。

## 使用

双击 `index.html` 用浏览器打开即可（也可以用 `python3 -m http.server` 起个本地服务）。

- 输入时即时转换，支持千分位（`1,234.56`）、全角数字（`１２３`）、`¥` 符号
- 结果区一键复制；`⌘/Ctrl + C` 也能直接复制大写结果
- 三个格式开关：加“人民币”前缀（**默认不勾**）、元后写“整”、不足一元写“零元”
- 最近记录保存在浏览器本地（`localStorage`），可点击回填
- 自动适配深色模式与手机屏幕

## 转换规则

依据中国人民银行《支付结算办法》附一[《正确填写票据和结算凭证的基本规定》](https://www.cncc.cn/zcfg/200903/t20090323_286.html)：

1. 大写数字：`零壹贰叁肆伍陆柒捌玖`，单位：`拾佰仟万亿`、`元角分`、`整`
2. 金额到「元」为止的，元后写「整」；到「角」为止的，角后可写「整」；有「分」的，分后不写「整」
3. 数字中间有 0 时写「零」，连续多个 0 只写一个「零」，如 `1001` → 壹仟零壹
4. 中文大写金额数字前应标明「人民币」字样，且应紧接填写，不得留有空白

> 关于第 4 条：规范票据填写应带「人民币」字样。界面上的「加"人民币"前缀」开关**默认不勾选**，
> 便于只取纯大写数字；需要符合票据规范时请手动勾选。
>
> 链接指向**中国人民银行清算总中心**官网（`cncc.cn`）发布的《支付结算办法》全文页面，
> 页面中「正确填写票据和结算凭证的基本规定」一节即本工具所依据的条文。
> 该页收录的是银发〔1997〕393号原文，未含 2024 年修改决定；后者仅删去第一百二十五条、
> 第一百九十二条第二款、第一百九十七条，**不影响本工具涉及的金额书写规则**。

## 测试

```bash
node test.js
```

覆盖 64 项断言：整数零的处理、每级单位（拾/佰/仟/万/亿）、零的合并、角分各种组合、
负数、非法输入拒绝、千分位与全角容错。

## 实现说明

金额全程用**字符串**运算，不经过 `Number`，避免浮点误差（`0.1 + 0.2 !== 0.3`）；
整数部分按 4 位一节从右往左分组，节权位为 `万 / 亿 / 万亿 / 亿亿`，最多支持 20 位整数。
